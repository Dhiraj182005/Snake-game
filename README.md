# Snake-game

🐍 Snake Game using Turtle in Python
This is a simple implementation of the classic Snake Game using Python's built-in turtle graphics module. The game runs in a GUI window and allows the user to control a snake to eat food, grow longer, and avoid hitting the walls or itself.

🎮 How to Play
Use the Arrow Keys (↑ ↓ ← →) to move the snake.

Eat the yellow food dot to grow longer.

The game ends if the snake collides with the wall or itself.

Your score increases each time the snake eats food.

📦 Requirements
Python 3.x

turtle module (comes pre-installed with Python)

No additional installations are needed.
